Чтобы установщик смог поставить обвязку, открой SSH-доступ в настройках своего MSB-бота.

Скрипты на сервере выполнять не нужно.

1. Открой своего MSB-бота в Telegram.
2. Зайди в Настройки.
3. Найди раздел доступа по SSH (открыть доступ / ключи / IP).
4. Добавь этот публичный ключ:

```
{{PUBLIC_KEY}}
```

5. Добавь в список разрешённых IP этот адрес (или адреса):

```
{{EGRESS_IPS}}
```

6. Сохрани настройки.
7. Пришли сюда хост сервера (IP или DNS) и нажми «Проверить и установить».

Если пункт меню называется иначе — ищи слова SSH, ключ, IP, доступ. После сохранения ключа и IP доступ обычно открывается за минуту.
