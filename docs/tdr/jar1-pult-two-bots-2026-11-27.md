# Пульт JAR1 с двумя ботами — 27.11.2026

До аудита обе службы, `msb-bot@default` и `msb-bot@mistrjarvis`, работали.
Свежие снимки Пульта содержали одного бота. На JAR1 сборщик стартовал в
07:51:33 UTC, профиль второго бота добавили в 08:39:26 UTC. Новое чтение
того же каталога уже находило оба профиля. В `f428aa0` автоматическое
обнаружение выполнялось только при загрузке конфигурации сборщика.

| Изменение состава | Изолированный сборщик на одном процессе добавил новый профиль на следующем цикле, привязал состояние failed к этому профилю и убрал удалённый автообнаруженный профиль. |
| Недоступный каталог | Переименование временного каталога раньше убирало второго бота без предупреждения. После правки оба остались в списке с предупреждением о чтении. Успешное чтение сняло предупреждение и применило действительное удаление. |

Проверки отказов и совпадений ID проведены на тестовых данных. В живом
расписании был системный таймер. У обоих ботов не было интервальных задач.
Хранилище `autonomy/tasks.json` остаётся вне источников текущего Пульта,
как зафиксировано в [предыдущем аудите](jar1-pult-audit-2026-11-27.md).

## Выкладки и откат

Каждое исправление установлено отдельно поверх предыдущего. На JAR1 каждый
пакет прошёл typecheck и четыре проверки операции выкладки. Число тестов
Пульта указано в таблице. Из изолированного набора исключены тест с
OpenClaw по решению владельца и один CLI-тест, которому нужен живой systemd.
Активность служб отдельно сверена на сервере. При каждой выкладке
перезапускался сборщик. PID ботов и веб-сервиса совпали до и после.
Пакеты содержали код Пульта и не включали настройки экземпляра, данные
