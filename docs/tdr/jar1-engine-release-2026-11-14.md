# Приёмка общих исправлений msb-engine на JAR1, 14.11.2026

JAR1 обновлён code-only выпуском `4568242e0d319ecb72919f01ea81eb8e86b79613`
(локальная метка `jar1-engine-4568242`) поверх `858fe91`. Это отдельная цепочка
для выпуска, а не HEAD рабочей ветки: в неё отобраны эквиваленты `03453da`,
`71734e7`, `18f2bb7`, `4af0fd0`, `46b5485`. Другие локальные этапы не вошли.
Подробное старое поведение, изменённые связи и проверки описаны в этих коммитах;
эта запись продуктовую логику не меняет.

Установлены 6 файлов бота и 5 системных файлов: приём и проверка запросов,
приватная атомарная запись состояния, пользовательское название службы, выбор
бота в настройках Пульта и метка `.off` после успешного запуска. После установки
сверены 326 файлов разрешённого кода и закрытая копия 11 прежних файлов.
Механизм установки контролировал снимок выбранных файлов профиля во время
остановки; его область явно указана в операторском отчёте и не покрывает
произвольные пути пользователя.

На JAR1 в изолированном каталоге прошли 1 093 JavaScript и 43 Python теста,
синтаксис 11 файлов; два Python теста пропущены из-за нужды в root и разных
UID. Все те же 45 Python и 1 093 JavaScript теста прошли в локальном
изолированном Debian-контейнере. Ранние серверные прогоны не прошли из-за
timeout: три случая затем прошли по отдельности последовательно, один из них
снова воспроизвёлся параллельно. Финальный полный разрешённый набор выполнен
с одним Node-файлом одновременно, не меняя самих проверок.

В Telegram после обновления `/status` подтвердил прежние Codex, модель, глубину
и сессию; на реальный короткий запрос бот ответил, наблюдались typing,
«Думаю…» и футер. Тестовый запрос просили не сохранять в память. Служба бота
active; системные path/timer остались inactive/disabled. Старая заявка status
сохранена, не выполнена и не удалена. Пульт и живые системные вызовы не
проверены, поскольку их службы выключены. По прямому решению владельца тесты
OpenClaw исключены: это не полный штатный gate и не проверка его совместимости
с общими изменениями. При отборе использован лексический фильтр тестовых
файлов; выборка и исключения перечислены в отчёте на сервере.

Обработка паузы Codex из смешанных локальных этапов и незавершённое
восстановление архива в выпуск не вошли. Их выделение и оценка необходимости
остаются отдельной работой без разработки и проверки OpenClaw. Также требуется
отдельно оценить частично активную службу при ошибке запуска и согласовать
необходимость включения системной службы/Пульта.
