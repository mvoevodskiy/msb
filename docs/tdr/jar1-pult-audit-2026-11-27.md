# Аудит Пульта на JAR1, 27.11.2026

Агент в Telegram нашёл три проекта в рабочих материалах. Пульт показывал
пустой список, потому что в его отдельном реестре карточек не было файла
`~/workspace/ops/pult/projects.json`. Действующие каталоги Atoll и Кронберга
видны в хранилище проектов бота. Agents Money зарегистрирован по сведениям
владельца и ответу агента, без предположений о каталоге и владельце карточки.

На JAR1 зарегистрированы три карточки штатной командой
`~/.msb/pult/bin/pult project set`. Основному боту привязаны Atoll и Кронберг,
у которых подтверждены каталоги. В источники сборщика добавлены действующие
службы Atoll и `clientdesk-atoll-backup.timer`. Расписание и службы берутся
из systemd. Предыдущий конфиг сохранён в закрытой копии
`/var/lib/msb-ops/releases/pult-project-data-2026-11-27/pult.config.json`.

Выпуск `f428aa075c848f82542ed4195a268a80fc1ad96e` проверен и установлен поверх
базы `740a8a0d93cbaa404130c122dbf1deefb6df47ac`. Изменено шесть файлов Пульта.

- `d8941b5` показывает число служебных юнитов, которые работают штатно.
- `4bb55b0` отмечает неполный расход, если журнал пуст, а ход зафиксирован в действии.
- `a3b1117` показывает недоступную квоту Codex вместо ложной отметки нормы.
- `e65e86f` отличает ошибку чтения реестра от пустого списка проектов.
- `d062e13` отличает недоступное расписание от отсутствия задач.

Proof SHA-256 `09bbdabc620e2e8f943fc345246e18255dde0729a82635684e0a656b146b0d70`.
На JAR1 изолированно прошли typecheck, 295 тестов Пульта и 4 проверки
оператора. Из набора исключены тест с OpenClaw и один CLI-тест, которому нужен
работающий systemd. Отказы источников проверены на фикстурах.

Живой Mini App показал три карточки, службы и последний коммит Atoll,
последний запуск бэкапа и следующий запуск в 06:30 по Москве. Переход из
ближайшего расписания открыл карточку таймера. Пульт показал `0 из 3` для
неактивных служебных юнитов. Число запросов за сутки совпало с числом записей
в журнале, расход Codex сошёлся по всем трём периодам, квота и графики были
доступны. После установки снимок свежий и без ошибок источников. Бот, веб-сервис
Пульта и Atoll сохранили прежние процессы. Перезапущен только сборщик.

Интервальные задачи из отдельного хранилища `autonomy/tasks.json` в текущий
сборщик не подключены. На JAR1 таких задач на момент проверки не было.

Выпуск можно откатить с прежним кодом из `/var/lib/msb-ops/releases/jar1-pult-audit-f428aa0`
с помощью [проверенной транзакции](../../tools/release/jar1-pult-warning/README.md)
и stage `/var/tmp/jar1-pult-audit-f428aa0`. Настройка карточек и мониторинга
сохраняется при кодовом откате.
