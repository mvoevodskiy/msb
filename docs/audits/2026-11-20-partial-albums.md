Статус: **verified-isolated**, 111 проверок прошли. Живая приёмка Telegram,
настоящего Codex CLI и развёртывание на JAR1 не проводились.

## Поведение

| Ситуация | Результат |
| --- | --- |
| Не скачалась часть фото, видео или документов | Остальные элементы обрабатываются; модель вызывается один раз |
| Сбой `getFile`, отсутствие пути, HTTP, transport, timeout или чтения ответа | Одна попытка для каждого элемента, без повторного скачивания |
| Частичный успех | В контексте модели указаны исходные позиции, доступные пути и пропуски |
| Подпись или цитата были у недоступного вложения | Подпись и цитата сохраняются |
| Сохранилось видео, но нет кадров или транскрипта | Сам MP4 остаётся доступным для анализа |
| Не скачалось ничего | Модель не вызывается; первая очищенная ошибка показывается прежним способом |
| `/stop` во время подготовки | Следующее скачивание и запуск модели не начинаются |
| Ошибка обязательной локальной записи или чтения | Ход завершается с ошибкой; такой сбой не скрывается частичным успехом |
| Все вложения доступны | Сохраняется прежний запрос модели, включая обычный текст и порядок файлов |

Исходные позиции в дополнительном контексте нужны, чтобы доступное второе
фото не было ошибочно принято за первое из присланных. Этот блок добавляется
только при частичном успехе и отдельно в Telegram не публикуется. Ответ самой
модели может естественно учитывать недоступные вложения.

Коллектор альбомов, время ожидания 2,5 секунды, очередь, пересланные документы,
статусы, кнопки и команды сохраняются. Уже начатая запись файла при отмене
может завершиться; сохранённые файлы не удаляются и не скачиваются повторно.

## `/undo` и границы этапа

`/undo` остаётся неподключённым. Текущий foreground Codex использует app-server,
другие заранее выбранные маршруты — `exec`. Ни один из этих адаптеров не
сохраняет исходные байты и надёжную принадлежность файловых правок конкретному
ходу. Существующие резервные копии относятся только к отдельным операциям
самого бота. Проверенная ранее локальная схема `thread/revert` меняет историю
разговора и прямо исключает откат файлов.

Актуальные исходники, ограничения и необходимая проверка захвата состояния
до/после операции описаны в
[parity-undo-evidence.txt](../../.msb/bot/tests/reference/parity-undo-evidence.txt).
Подмена файлового отката сбросом Git или откатом истории не выполнялась.

Этот этап закрывает только частично доступные альбомы. Остальные непроверенные
сценарии второго аудита остаются отдельным списком; 111 PASS не являются
подтверждением всей кодовой базы. Отдельная работа по OpenClaw остаётся на паузе.

Старый референс и точные границы заимствованного поведения сохранены в
[контракте](../../.msb/bot/tests/reference/partial-album-contract.txt).
Откат функции — `git revert` runtime-коммита `f5ccf48`.
Миграций данных, изменений конфигурации и выкладки работающего бота нет.
