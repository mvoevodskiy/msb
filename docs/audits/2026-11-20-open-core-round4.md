## Почему исходные тесты падали

### 1. Итоговый футер искали среди редактирований статуса

Тест `real Telegram message handler attaches the measured compact footer`
ждал `f.edits`, тогда как уже принятый маршрут
[response.mjs](../../.msb/bot/src/telegram/response.mjs) отправляет итог
через `ctx.reply`. Обвязка теста сохраняет такие ответы в `f.messages`.

В [коммите cdc7e3bd](https://github.com/SergeyKoleda/Jarvis/commit/cdc7e3bd064c61eb9aacf29a6dc077ef0c724915)
тест проверяет одно итоговое сообщение и один вызов модели с исходным
запросом. Проверки времени, компактного индикатора `○○○ 15%` и отсутствия
развёрнутой строки токенов сохранены. UI-группа: **192/193 → 193/193**.

В том же коммите убран цикл из `engine-menu.test.mjs`: переменная `snap`
никогда не передавалась в `enginesScreen(state, env, provider)`, поэтому
три итерации выполняли одинаковый код. Все пять утверждений оставлены
один раз, название больше не обещает проверку разных снимков состояния.
Этот тест проходил и до изменения. Переименованный вариант включён в
финальный прогон 603 проверок.

### 2. Тестовый Codex не поддерживал текущий переход в обычный диалог

После знакомства и частной сводки обычный Telegram-запрос получает
`onSteerReady` через
[bot.mjs](../../.msb/bot/src/telegram/bot.mjs) и
[turn.mjs](../../.msb/bot/src/agent/turn.mjs).
[Адаптер Codex](../../overlay/bot/ext/adapters/codex.mjs) выбирает
app-server для такого foreground-запроса. Само знакомство и частная
сводка продолжают использовать `exec`.

Старая заглушка CLI умела отвечать только на инициализацию и чтение
метаданных app-server. Она не отвечала на `thread/start` и `turn/start`.
Дополнительно часть проверок ожидала финал среди редактирований статуса.
Поэтому не завершались проверки девятого запроса, остановки, сброса,
восстановления и единственной доставки.

[Коммит 6ad74041](https://github.com/SergeyKoleda/Jarvis/commit/6ad74041c44b638b342f317584ca18c05f68a114)
меняет только [codex-bootstrap.test.mjs](../../.msb/bot/tests/codex-bootstrap.test.mjs):

- Заглушка подтверждает инициализацию, открытие/возобновление потока,
  запуск хода и события ответа, использования токенов и завершения.
- Поддержаны оба фактических расположения `app-server` в аргументах:
  перед флагами в [чтении метаданных](../../overlay/bot/ext/codex-app-read.mjs)
  и после флагов в [обычном ходе](../../overlay/bot/ext/adapters/codex-app-server.mjs).
  Первый промежуточный прогон выявил пропуск первой формы в новой заглушке;
  в итоговом варианте исправлены обе формы.
- Вызов модели записывается при `exec` или `turn/start`, а не при чтении
  метаданных. Сохранены проверки каталога, профиля, возобновления,
  однократного входного текста и отсутствия повторной загрузки медиа.
- При закрытии stdin удерживаемая заглушка завершается без сообщения
  об успехе. Сохранены остановка, сброс, журнал, перезапуск и охрана
  повторной доставки. Для девятого запроса явно проверяется одна сводка
  через `exec` и один обычный ход через app-server.
- Только финальные ответы наблюдаются через `messages`; проверки
  редактирования при остановке без частичного ответа и при отдельном
  рассмотрении восстановления сохранены.

В исходной группе было **244 реальных проверки: 228 PASS, 16 FAIL**.
Node дополнительно вывел file-level отметку для целиком отфильтрованного
файла политики OpenClaw — она не посчитана тестом. Этот файл удалён из
исполняемого перечня. Одна чистая Codex-проверка сохранности чужих каталогов,
излишне исключённая сначала, возвращена: она не активирует OpenClaw.
Итог группы: **18 файлов, 245/245 PASS**.

## Воспроизведение

Финальный запуск: Node **24.22.3**, `--test-concurrency=2`,
`--test-timeout=30000`, пустые временные `HOME` и `TMPDIR`, минимальное
окружение. Новый сетевой namespace оставляет интерфейсы выключенными.
HTTP используется только через подставные ответы, MCP — через stdio.
Нативные аккаунты и пользовательские профили не нужны.

Из корня репозитория, указав путь к Node 24:

```sh
export NODE24=/opt/codex/runtimes/codex-primary-runtime/dependencies/node/bin/node
python3 - <<'PY'
import json, os, subprocess, tempfile
from pathlib import Path

audit = Path('docs/audits')
files = (audit / '2026-11-20-round4-tests.txt').read_text().splitlines()
patterns = json.loads((audit / '2026-11-20-round4-excluded.json').read_text())
node = os.environ['NODE24']
args = ['unshare', '--user', '--map-root-user', '--net', node,
        '--test', '--test-reporter=tap', '--test-concurrency=2',
        '--test-timeout=30000', '--test-skip-pattern=^(?:' + '|'.join(patterns) + ')$',
        *files]
with tempfile.TemporaryDirectory(prefix='jarvis-round4-') as home:
    temporary = Path(home) / 'tmp'
    temporary.mkdir()
    env = {'HOME': home, 'TMPDIR': str(temporary),
           'PATH': str(Path(node).parent) + ':/usr/bin:/bin',
           'LANG': 'C.UTF-8', 'TZ': 'UTC'}
    result = subprocess.run(args, env=env)
raise SystemExit(result.returncode)
PY
```

Вывод финального TAP: 599 верхнеуровневых результатов и 4 вложенные
проверки, всего **603/603**. Код выхода — **0**; время TAP — **40,98 с**.
Полные точные фильтры сохранены в
[round4-excluded.json](2026-11-20-round4-excluded.json).
После прогона проверено отсутствие всех 31 отложенных имён в TAP и
наличие возвращённого Codex-only сценария. Независимое ревью подтвердило
обе формы CLI, завершение удерживаемой заглушки и сохранность утверждений.
`git diff --check` прошёл.

## Что остаётся непроверенным

**OpenClaw.** Полностью отложены шесть файлов из
[round4-unrun.txt](2026-11-20-round4-unrun.txt): четыре отдельных набора
MCP/напоминаний/чтения навыков/хода OpenClaw, `skills-openclaw` и

политики зеркалирования в OpenClaw и поэтому исключён целиком.
Ещё 31 точное имя отложено внутри смешанных наборов: 13 в группе UI,
15 в группе инструментов и 3 в группе адаптеров/запуска. Если один тест
содержит общую и OpenClaw-часть, отложен весь тест. Инертные подписи или
чужие каталоги в общих Codex-проверках не означают запуск OpenClaw.

**Живые внешние зависимости.** Настоящие Codex CLI/app-server, авторизация,
модели, Telegram и выпуск JAR1 не проверялись. Ранее отмеченная в первом
проходе зависимость native Codex probe от `MSB_TEST_CODEX_NATIVE` и
подходящего изолированного CLI остаётся внешним условием. Заглушка
bootstrap моделирует только используемую этими сценариями часть протокола.

**Полнота инвентаря.** До этого прохода четыре сохранённых перечня выбирали
143 уникальных тестовых файла. Добавлены ещё 64: теперь **207 из 213**
файлов `*.test.mjs` хотя бы раз включены в записанные изолированные прогоны.
Разность — шесть отложенных файлов. Это учёт файлов, а не утверждение
о выполнении каждого вложенного сценария, всех возможных ситуаций или
живой приёмке. Нереализованный `/undo` и неоднозначные продуктовые вопросы
из прежних отчётов этим проходом не закрываются.
