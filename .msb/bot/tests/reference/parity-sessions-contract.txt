ИСТОРИЯ И АВТОМАТИЧЕСКАЯ АКТИВАЦИЯ — РАЗНЫЕ РЕШЕНИЯ (fidelity correction)
Old tE/worker записывает каждый достоверный возвращённый native ID, в том числе
error/abort первого хода и позднее завершение после newtask/project/session switch.
Это не обход reset: история всегда разрешала явный выбор после сброса, без
автоматической активации. Прежнее требование этого контракта «только accepted
placement/same fence» было лишним ограничением и отменено до любой выкладки.
Writer использует captured provider/project; новые row не привязывать к случайному
текущему проекту после await (old GB.activeProject race исправляется по actual cwd).

Active ccSessionId/parked slots/usage/context по-прежнему защищены всеми epoch,
provider,project и first-token fences. Их запрет на автоматическое сохранение
не отменяет историческую запись реального завершившегося вызова. Late metadata
не трогает новую reservation или выбранные ID/usage. First error/abort с реально
наблюдавшимся своим native ID индексируется, но не активируется автоматически.
Foreign/sentinel/выдуманный ID исключаются. Из runClaudeTurn нужны внутренние
факты о запущенном процессе и ID из init/result. При остановке первого Codex
хода используется также достоверный thread.started, переданный до завершения
процесса. Этот предварительный ID предназначен только для истории отменённого хода.
Ранее известный resume ID после запущенного вернувшегося вызова тоже учитывается.
Отмена до запуска, исключение подготовки и ненаблюдённый ID истории не создают.
Принадлежность ID проверяется по провайдеру, захваченному при начале хода.

Count/lastPrompt/lastActivity меняются в порядке ЗАВЕРШЕНИЯ каждого engine pass,
как tE, не «последний start побеждает». Atomic read/modify/write не теряет инкременты;
existing firstPrompt/project/startedAt не переписывать. Completion-order не менять
по собственной рекомендации; это было бы отдельным согласуемым отличием.
Displayprompt bounded200 с общей journal redaction/Unicode clip. Не retro-import
старые native histories/userfiles и не выдумывать firstPrompt/COUNT приboot/чтении.
