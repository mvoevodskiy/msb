CLI каталог и чтение
Z4 последовательно сканирует HOME/.claude/skills и base/.claude/skills как
workspace, затем captured currentcwd/.claude/skills как project, если отличается
от base. HOME не сканируется дважды при строковом совпадении с base/current.
LG рекурсивно обходит реальные Directory entries и читает только SKILL.md;
symlink directory не является isDirectory, file symlink SKILL.md читается как
обычный файл. Ошибка каталога/файла пропускается, другие файлы не открываются.
Явной сортировки и дедупликации имён/relativepaths нет; сохраняется порядок
readdir и последовательность корней. Не вводить precedence слияния по имени.

bHA — не YAML parser: frontmatter начинается с---LF и заканчиваетсяLF---,
name/description берутся regex, disabled только точная строка disabled:true
с допустимым regex whitespace. Имя fallback=parent basename; описание fallback=
первая строка '# ', иначеempty. Size=Buffer.byteLength всего SKILL.md, UTF8.
Path=relative(root,dirname(file)); type=system при startsWith('_always'), иначеuser.
UI скрывает только точное name==='system', а не type; disabled строки остаются
в счётчиках и показываются с⏸, обычные с🧠. Native enable config не менять.
