Модель Claude и сохранность беседы
Old Ey52406–52414 проверяет выбранную модель/lock и меняет только ccModel.
I253190–53220 сохраняет state и возвращает agent screen без очистки ccSessionId.
Глубина: K0A52558–52615 и setter53222–53289; допустимы low/medium/high/xhigh/max,
setter не сбрасывает Claude session. off в old относился к OpenClaw, не Claude.
Новая applyModelFamily до исправления очищает ccSessionId и резерв первого старта;
это ошибочно начинает новую беседу при следующем сообщении. Менять только модель,
сохраняя native ID, provider slots, sessionEpoch и ещё не завершённый первый старт.
Явный /newtask/clear, переключение provider, новый competing start и ошибка/abort
продолжают использовать существующие fences: их нельзя ослаблять ради модели.
Проверка должна идти через callback и через активный production runAgentTurn.
Поддержка каталога/CLI-version locks пока требует отдельной проверки, не PASS.

Режимы
Old YTA54924–54968 показывает ровно auto/control/plan. smart скрыт из UI,
но принимается прямым callback. I252646–52658 нормализует неизвестное значение
в auto (НЕ игнорирует его), сохраняет режим и начинает новую Claude-беседу.
Нельзя выдать игнорирование invalid за old контракт. New core сохраняет любой
суффикс, а overlay уже использует old fallback. Явные mode/reset fence сохранять.
Old ni20377–20398: auto/control/plan→acceptEdits, smart→auto. Plan/control —
разговорный protocol через prompt/кнопки, не native CLI plan-only restriction.
Новый resolvePermMode передаёт plan как native plan и не подключает разговорный
protocol; это отдельное воспроизводимое расхождение.

Подтверждение плана
Old injections19445–19447 и тексты20939–20951 задают control/plan просьбы модели.
Parser rkA105594–105624 убирает [КНОПКИ: control|plan|approve] и распознаёт
старые fallback фразы. akA105627–105640 строит прежние keyboard варианты.
Финальная доставка106584–106586/107155 и callbacks120920–120948 отправляют
продолжение в общую очередь, а не в отдельный runner. approve: «✔ Продолжай
выполнение.»; always: «☑ Разрешаю это действие всегда. Продолжай.»; skip:
«✖ Пропусти это изменение, продолжай дальше.». always не меняет постоянные права.
reject сообщает «✖️ Задача отменена. Напиши что изменить.», без модельного хода.
comment119288–119300: следующий текст становится «✖ Не согласен. Комментарий:
<text>». Точные связи финальной доставки/ошибки/отмены проверяются до реализации.
New handleMiscRoute пока только сообщает о неподключённом обработчике.

Согласованные отличия
Codex — отдельный backend/store/model/effort/native session, не Claude aliases.
Владелец сохранил исходный полный доступ и approval=never; этот аудит НЕ меняет
native права Codex. Сохранённый UI mode у Codex ранее явно обозначен как настройка,
не фактическое ограничение; не включать его prompt/native gate самовольно.
Раздельные provider sessions и их parked slots сохраняются при возврате.
Владелец сам выбрал low на JAR1: не восстанавливать прежний xhigh из backup.
Изолированные tests используют synthetic HOME/CLI/Telegram, не личный контекст
или токены. Live Claude/внешние авторизации не считать проверенными по fake CLI.

Доставка/навигация
Изменённая связь документируется у кода/импортов и в ближайшем README. Не вести
ещё одну карту файлов и не переносить old bundle в runtime. Каждый logical этап
имеет отдельный подробный commit с RED/GREEN и границами/откатом.

Глубина Claude — точная old политика
DC275–287 запрещает настройку Haiku4.5. nU809–817 не передаёт --effort для
неподдерживаемой модели; yW792–807 сводит xhigh/max к high для non-Opus и
проверяет список effort у Opus. Каталог406–410/489–503: Opus4.6 поддерживает
low/medium/high/max, но не xhigh. K0A52558–52615 показывает raw выбранный уровень
и отдельно честную подсказку, во что он отображается; setter53275–53289 принимает
только5значений, сохраняет preference без нормализации и не сбрасывает беседу.
На baseline c76d8a3 aliases resolveModel были закреплены на Opus4.6/Sonnet4.6/Haiku4.5/Fable5;
этот узкий этап не заменяет каталог и не заявляет перенос CLI-version locks.
Нормализовать только фактический flag, не переписывать сохранённый preference,
не менять отдельный provider effort и native config Codex из обработчика Claude.

Последующий этап каталога (контракт parity-model-catalog-contract.txt) возвращает
native aliases и весь V1 metadata/CLI locks. Прежний текст о concrete aliases
выше относится к baseline c76d8a3, не к новой policy. Explicit legacy off остаётся
без outgoing flag; FY preferred default применяется только при unset, без
перезаписи raw field. Initial xhigh относится лишь к новому профилю, не к legacy unset.
