Новое расхождение
validateEnvValue проверяет только string/CR/LF/NUL, а форма заранее trim().
Пустота, лишние control, oversized value и явный другой vendor проходят;
граничный CR/LF теряется. Direct writer сохраняет сырые пробелы. Нужен
production RED перед изменением, не считать source review полным доказательством.

Распределение ответственности
Один pure value module: raw value + key → normalized string либо error без
секрета. Общие store/form должны использовать его, без второго copy validator.
Форма проверяет raw до transient description draft; invalid остаётся на value,
с исходным TTL, без записи/описания/CLI. Retry/cancel действуют как прежде.
Store повторяет guard до IO/очереди, protected priority сохраняется; auth/Pult
используют те же существующие paths. Новых issuer/real-auth/network checks нет.
