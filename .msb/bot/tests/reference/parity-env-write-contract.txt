Граница исправления: одна общая process queue для существующих set/delete/
provider-secret writers. Не менять parser/format/keys/auth/privacy/путь записи,
не перенаправлять default per-bot в global, не копировать старое удаление дублей
из чужих bot scopes, не вводить OS/helper/CLI-authority changes.

Ошибка одного writer возвращается только его caller и освобождает очередь;
следующая операция снова работает. Env объект обновляется после успешного rename.
Один target вычисляется при поступлении, а не из другого профиля после await.

readFile. Удержать read A, вызвать B: baseline B успевает сохранить старый snapshot,
