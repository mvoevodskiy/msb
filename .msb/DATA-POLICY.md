# Политика сбора данных — Constructor Agent

## Что собираем

Ваш агент отправляет два типа данных на наш сервер:

### Heartbeat (каждые 5 минут)
- Использование диска (%)
- Использование памяти (MB)
- Uptime процесса
- Версия бота
- Наличие активной сессии Claude Code

### Sync (каждые 30 минут)
- Статистика сессий Claude Code: количество сообщений, использованные инструменты, стоимость
- Ошибки (для диагностики)

## Зачем

- **Мониторинг здоровья** — мы видим если ваш VPS перегружен или бот упал, и можем помочь до того как вы заметите проблему
- **Техподдержка** — при обращении мы видим контекст (какие инструменты использовались, были ли ошибки)
- **Улучшение агента** — анонимная статистика помогает делать бота лучше

## Что НЕ собираем

- Содержимое ваших файлов и проектов
- Персональные данные за пределами сессий Claude Code
- Пароли, токены или ключи из ваших проектов

## Наш доступ

Пользователь `msb-admin` используется для обновлений бота и диагностики. Мы заходим на ваш VPS только для:
- Обновления версии агента
- Диагностики при обращении в поддержку
- Исправления критических проблем

## Отключение

Вы можете остановить сбор статистики:

```bash
sudo systemctl stop msb-sync.timer    # остановить sync
sudo systemctl disable msb-sync.timer # не запускать после перезагрузки
```

**Важно:** при отключении мониторинга мы теряем возможность проактивно диагностировать проблемы. Доступ к каналу и материалам сохраняется.

Heartbeat (здоровье VPS) работает внутри бота и необходим для базового мониторинга.
