# Пульт — интерфейс (src/ui)

Статические файлы без сборки и без зависимостей. Веб-сервис отдаёт `index.html` на `/`, остальное — из `/ui/*`
(модули `*.js` — с типом `text/javascript`). Данные — только из API: `GET /api/snapshot` (каждые 30 с и при возвращении
на вкладку), `GET /api/history?range=24h|7d|30d` (графики сервера и мини-графики обзора), `POST /logout`. Ответ 401 → `/login`.

## Как устроено

| Файл | Что внутри |
|---|---|
| `index.html` | каркас: шапка с вкладками и «Выйти», плашки, `main`, нижняя навигация телефона, подсказка, живой регион для чтеца |
| `app.js` | состояние, опрос, маршруты (hash: `#/`, `#/bots`, `#/tasks`, `#/tasks/<id>`, `#/projects`, `#/server`; фильтры и период — `?bot=`, `?range=`), перерисовка графиков по ширине |
| `logic.js` | чистая логика без DOM: время в МСК (через Intl), числа по-русски, сводки, группы, «наблюдения». Типы — `logic.d.ts` |
| `dom.js` | `h()`/`s()` — построение DOM только текстовыми узлами (innerHTML не используется), подсказки, наведение/клавиатура/касание на графиках |
| `charts.js` | SVG-графики руками: линия с перекрестием, мини-график, столбики ходов, лента «кто что делал», полоса суток |
| `view-*.js`, `parts.js` | экраны и общие кусочки |
| `app.css`, `auth.css` | тёмная тема (макет v2); `auth.css` — страницы входа, классы договорные (см. `src/server/pages.ts`) |

Правила: цвет — только у того, что требует внимания (красный — решения и тревоги, жёлтый/оранжевый — внимание,
зелёная точка — в норме), рядом с цветом всегда слово. CSP: `script-src 'self'` — без инлайн-скриптов и `onclick=`.
«Сейчас» считается по часам веб-сервиса (`receivedAt + ageSec`), а не браузера.

Плотность v3 (06.11.2026): первый взгляд — решения и внимание; норма свёрнута через нативный `<details>`
(`fold` в `parts.js`). Макеты — `concept/v3/`.

## Проверить

```bash
npm run typecheck && npm test                     # логика и статические проверки: tests/ui/*.test.ts
node tests/ui/preview-server.ts --port 8790       # предпросмотр на фикстурах: http://127.0.0.1:8790/?fx=full
node tests/ui/shots.ts [фильтр]                   # снимки экрана → tests/tmp/ui-shots/, ошибки консоли → код 1
node tests/ui/make-fixtures.ts                    # пересобрать tests/fixtures/ui/*.json из макетов concept/v2
```

Фикстуры предпросмотра (`?fx=`): `full`, `stale` (данные устарели), `empty` (сборщик ещё не прислал), `quiet` (нет задач,
вопросов и тревог; есть ошибки источников и уведомлений), `offline` (обрыв связи), `unauth` (401), `error500`, `nohist`.
Снимки экрана используют Playwright из проекта zapcita (в зависимости Пульта не входит).
