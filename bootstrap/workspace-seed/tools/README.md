# Инструменты агента

Скрипты под действия, которые повторяются от раза к разу с минимальными изменениями: остатки, расход, сверки, статусы. Повтор выполняет скрипт, а не новый проход ИИ (см. CLAUDE.md → «Инструменты под повторяющиеся действия»).

## Реестр

| Инструмент | Что делает | Как вызвать | Платно? | Секреты |
|---|---|---|---|---|
| `deepgram.ts` | остаток проекта Deepgram, список ключей, расход по ключам за период | `~/workspace/tools/deepgram.ts` · `… keys` · `… usage --from 2026-10-01 --to 2026-10-25` | нет | `DEEPGRAM_API_KEY` с правами admin |
| `proxyapi.ts` | остаток ProxyAPI в рублях, напоминание ниже 50 ₽ | `~/workspace/tools/proxyapi.ts` | нет | `PROXYAPI_KEY` |
| `names.ts` | свободны ли имя-домен (WHOIS/RDAP по зонам, по умолчанию 13: ru, рф, com…) и имена в Telegram (t.me + Fragment) и ВКонтакте; итог «полностью свободно» | `~/workspace/tools/names.ts acme demo --social tg,vk` · `… пример --zones рф,com --json` | нет | нет |
| `gitflic.ts` | конвейеры GitFlic: список, отчёт задачи, ожидание выкладки коммита, служебные задачи (OPS) с отчётом | `~/workspace/tools/gitflic.ts ops ВЛАДЕЛЕЦ/ПРОЕКТ check` · `… wait ВЛАДЕЛЕЦ/ПРОЕКТ --commit SHA` · `… pipelines ВЛАДЕЛЕЦ/ПРОЕКТ` | нет | `GITFLIC_TOKEN` пользователя-агента (PROJECT_READ; для ops — PROJECT_WRITE) |

Свои инструменты проекта клади в `~/projects/<имя>/` (`scripts/`, `tools/`, README) — не в этот реестр ядра.

## Как устроено

- TypeScript без сборки и зависимостей: Node 22 сам убирает типы. Файлы исполняемые, `--help` у каждого.
- `lib.ts` — общее: HTTP-запрос с тайм-аутом, ошибки по-русски, деньги и падежи.
- Каждый инструмент экспортирует `run(argv, deps)`: тесты зовут его с подменными `fetch` и окружением, без сети.
- Вывод по-русски для человека, `--json` — для скриптов и фоновых задач.
- Код выхода: 0 — успех, 1 — ошибка (нет ключа, сервис не ответил, HTTP-ошибка), 2 — неверный вызов.
- Ключи берутся только из окружения и в вывод не попадают.

## Проверка

```
cd ~/workspace/tools && npm test
```

## Как добавить инструмент

1. Сначала посмотреть реестр: возможно, нужное уже есть — тогда дописать параметр, а не плодить второй скрипт.
2. Новый `имя.ts` по образцу `proxyapi.ts`: справка, `run`, `main(import.meta.url, run)`, `chmod +x`.
3. Тесты в `tests/имя.test.ts`: успех, каждая ошибка, неверный вызов, ключ не попадает в вывод.
4. Строка в реестр выше: что делает, как вызвать, платный ли, какие секреты.
5. Коммит.

Платный вызов (модель, распознавание, отправка) — только по явному флагу, цена — в `--help`.
