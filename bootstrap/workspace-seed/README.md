# workspace-seed

Канонический **пустой** workspace для bootstrap чистого оркестратора.

Сюда не кладут личность владельца, названия продуктов и историю с боевых серверов.
Каталог `workspace/` в корне репо может содержать археологию снимка — **install.sh
ставит только этот seed**.

См. также: `../UPDATE-POLICY.md`.
