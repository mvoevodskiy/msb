## Проверки

Регрессия RED воспроизвела футер без 4%. После исправления прошли 60
связанных тестов локально. Те же 60 тестов прошли на JAR1 на Node v22.23.5
с read-only зависимостями, синтетическим HOME и без внешней сети.
Первый изолированный запуск выявил ошибочный путь до node_modules.
Повтор на том же архиве использовал корректный путь.

После перезапуска обе службы дошли до polling ready. Файлы env, хранилища
провайдеров, общая авторизация и конфигурация Codex, выбранные настройки и
активные ID сессий совпали при сверке до и после перезапуска.

В Telegram новый ответ второго бота показал «⏱ 7.4s · ○○○ 6%».
Установленный форматтер отдельно вернул «⏱ 15.8s · ○○○ 4%» для исходного
замера. Обе службы остались active, NRestarts=0. Проверка охватывает
футер Codex, связанные сценарии доставки и запуск обеих служб.

## Кодовый откат

Закрытая копия находится в /var/lib/msb-ops/releases/jar1-codex-footer-ec60d3ccbcc2.
Файл record.json содержит имя цели, обе контрольные суммы, владельца и
режим исходного файла. Для отката при отсутствии активных ходов остановить
msb-bot@default.service и msb-bot@mistrjarvis.service, сверить хеши и атомарно
вернуть только response.mjs из закрытой копии с его прежними правами.
После запуска обеих служб проверить polling ready и ответ в Telegram.
