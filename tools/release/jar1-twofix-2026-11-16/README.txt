JAR1 — выборочный code-only выпуск двух исправлений, 16.11.2026

База — установленный da0f05658d69c1cd3d48ad9436d998ce10dbca8b. В пакет
попадают три связанных JS-модуля фонового ответа, bot-ctl.sh и новая общая
библиотека msb-fstab.py. Другие provider runtime, OpenClaw, системные настройки,
auth и сессии не входят в payload. Bootstrap на сервере не запускается;
существующий /etc/fstab не изменяется. В старых строках дополнительные
параметры автоматически не меняются.

build.py экспортирует код и тесты только из одного Git-коммита, проверяет
состав отличий и побайтовое совпадение двух копий bot-ctl. verify.py запускает
в разрешённом изолированном окружении тесты Codex и общих маршрутов; модули
несвязанного диспетчера подменены, сценарии OpenClaw исключены. Fstab-тесты
работают исключительно с временными файлами и фиктивными командами mount,
включая фрагменты установщика; настоящих mount/изменений /etc не выполняют.

Перед выпуском deploy.py проверяет старый инвентарь, контрольные суммы и
полный разрешённый отчёт тестов, владельца и режим административного скрипта,
отсутствие административных процессов и доступность всех файлов для отката.
Во время публикации нельзя параллельно запускать bot-ctl или админ-операции:
их проверка по /proc не обеспечивает взаимной блокировки внешних команд.
Библиотека публикуется первой, скрипт затем; при откате порядок обратный.

Оператор создаёт закрытую проверенную копию профиля и нативных сессий в
BACKUP/profile, используя SQLite backup API и сверку состояния. В копии есть
секреты и личные данные: root 0700, файлы 0600, не переносить в Git. Копия на
том же диске не защищает от отказа сервера. Сессия/профиль не перезаписываются.

В случае сбоя действует проверенный code-only rollback; ручной вызов:
python3 -I -B STAGE/deploy.py --stage STAGE --backup BACKUP \
  --manifest-sha MANIFEST_SHA --report-sha REPORT_SHA --rollback
Проверить, что другие вызовы bot-ctl/helper отсутствуют. Откат касается кода,
не возвращает историю и настройки поверх текущих данных. Личную копию профиля
можно восстанавливать только отдельно с учётом появившихся новых данных.
