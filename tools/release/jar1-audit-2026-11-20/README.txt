JAR1 — выборочный code-only выпуск аудита Codex и общих маршрутов

База: 5a0dbf39dbd81f1c564440b317928785f6635f39, ранее установленный
выпуск. Новый исходный commit должен быть его потомком и содержать ровно 19
заданных runtime-файлов: 18 замен и новый src/autonomy/run-journal.mjs. Код
выбран из рабочей ветки после b01379e; отложенные engine/OpenClaw, отдельный
MCP-мост и не перенесённые новые провайдеры в payload не входят. Сборщик
отвергает иные runtime-изменения. Исходник, тесты и оператор экспортируются
из одного commit; после экспорта патчи не накладываются.

Root-owned launcher.py запускает полный разрешённый scoped suite на JAR1 в
network/mount/PID namespaces, с синтетическим HOME и только loopback. Отдельные
сценарии OpenClaw исключены. Два общих scheduler-теста выполняются после
подмены неиспользуемого диспетчера до импорта. Смешанный Codex bootstrap-файл
допускается только при точном исключении одного несвязанного сценария; изменение
границ исключения блокирует выпуск. Предыдущие проверки очереди, Claude и
native Codex 0.166.0 остаются. Дополнительно обязательны 43 проверки первого
запуска и 133 проверки новых исправлений. Точный manifest/report проверяются
оператором до остановки службы; тестовые данные и auth синтетические.

Перед установкой сверяются полный базовый inventory, состояние службы,
отсутствие активного хода, Node/CLI/dependencies и владельцы файлов. Сначала
создаётся закрытая копия auth/env, настроек и сессий с SQLite backup/quick_check;
активная Codex-сессия сверяется с ней после старта. Содержимое профиля в Git не
попадает. Кодовый откат проверяет inode/хеш нового файла и возвращает только
код, не перезаписывая живую историю или профиль.

Локальная проверка оператора: python3 -B -m unittest discover -s
 tools/release/jar1-audit-2026-11-20 -p 'test_*.py'. Успех локальных тестов не
заменяет полный проверенный пакет на JAR1 и отдельную живую приёмку Telegram.
Не применять общий полный релиз или bootstrap/OS-миграцию в рамках этого
этапа. При несоответствии состояния не ослаблять проверки для установки.
